# MediaWall — Figma

Импортируйте `desktop.svg`, `mobile.svg` и `upload-dialog.svg` в Figma через перетаскивание файлов на холст. SVG содержит редактируемые векторные элементы и подписи. Это макеты для учебного проекта, а не файл `.fig` и не ссылка на готовый облачный проект Figma.

Основные цвета: `#FAFAFA`, `#171717`, `#777777`. Размеры фреймов: 1440×900, 390×944, 480×560.

После импорта сохраните дизайн в командном проекте Figma и добавьте ссылку в корневой README репозитория.
